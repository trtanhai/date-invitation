# Date Invitation

A responsive Vietnamese date-invitation microsite.

## Customize
Open `index.html` and replace:
- `[Tên cô ấy]`
- `[Thứ/ngày] · [Giờ]`
- `[Quán cà phê / địa điểm]`

## Run locally
Double-click `index.html` or open it in a browser.

## Publish for free
1. Create a GitHub repository (for example `date-invitation`).
2. Upload `index.html`.
3. Open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch, select `main` and `/ (root)`, then Save.
5. Wait for the public Pages URL to appear. Send that URL to her.

You can also deploy the folder with Netlify Drop.
